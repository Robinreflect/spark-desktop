# Reflect Spark voor de desktop

Hier staan de installatiebestanden van Reflect Spark voor Mac en Windows. Spark is het AI-team van je bedrijf: agents
die meewerken in je mail, je offertes en je planning. Meer over Spark: [reflectspark.io](https://reflectspark.io).

## Downloaden

- **Mac** (Intel en Apple Silicon): [Spark-Mac.dmg](https://github.com/Robinreflect/spark-desktop/releases/latest/download/Spark-Mac.dmg)

Open het bestand en sleep Spark naar Programma's. De eerste keer vraagt Spark de naam van je omgeving; die kreeg je
van je beheerder.

De app is een venster om je eigen Spark. Je gegevens staan op de server van je bedrijf, niet in de app.
